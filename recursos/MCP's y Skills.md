
> [!info] Qué es un MCP
> Un MCP (Model Context Protocol) es un conector estándar que le permite a un modelo de IA hablar con herramientas externas (un calendario, una base de datos, un servicio web) sin que tengas que programar esa conexión desde cero.

> [!info] Qué es un Skill
> Un Skill es un procedimiento guardado que la IA puede reutilizar: instrucciones, plantillas o scripts para una tarea específica, para no tener que explicarla desde cero cada vez.

## Directorios de MCP

- **[mcpservers.org](http://mcpservers.org/)**: catálogo de servidores MCP existentes, organizado por categoría.
- **[mcp.directory](https://mcp.directory/)**: otro catálogo de servidores MCP.

## Directorio de Skills

- **[skills.sh](https://www.skills.sh/)**: skills ya creados por la comunidad, listos para usar o adaptar.

## Framework para crear agentes

- **[Vercel Eve](https://vercel.com/eve)**: framework para construir agentes de IA personalizados. Se instala desde la terminal con:
  ```
  npx eve@latest init my-agent
  ```
  Documentación en **[eve.dev](https://eve.dev/docs/getting-started)**.
