> [!info] Qué es el control de versiones
> Git guarda el historial de cambios de tus archivos: puedes ir hacia atrás, comparar versiones o compartir tu trabajo sin miedo a perder algo. GitHub es donde se guarda una copia de ese historial en internet.

## Herramientas

- **[Git](https://git-scm.com/)**: el programa de control de versiones. Se instala en tu computadora.
- **[GitHub](https://github.com/)**: plataforma donde se alojan repositorios de Git en la nube.

## Documentación

- **[Referencia de comandos de Git](https://git-scm.com/docs/git#_git_commands)**: la lista completa y oficial de comandos de Git.

## Markdown

- **[Guía de sintaxis básica](https://www.markdownguide.org/basic-syntax/)**: cómo se escriben encabezados, listas, negritas y enlaces en Markdown.
- **[Mermaid](https://mermaid.js.org/):** Crear diagramas y gráficos dinámicos utilizando texto plano y una sintaxis inspirada en Markdown.
- **[TikZ](https://tikz.dev/):** Crear elementos gráficos para latex, también puede ser usado en obsidian. 
- **[Plantillas para Obsidian](https://github.com/llZektorll/OB_Template/tree/main)**: plantillas de nota ya armadas, para quien quiera que sus notas se vean más cuidadas.
