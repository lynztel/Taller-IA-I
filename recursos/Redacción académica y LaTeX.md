> [!info] Qué es LaTeX
> LaTeX es un sistema para escribir documentos con muchas fórmulas o referencias bibliográficas, típico en economía, matemáticas e ingeniería. Se escribe como código y se compila a PDF.

## Instaladores

- **[MikTeX](https://miktex.org/download)**: distribución de LaTeX para Windows.
- **[Strawberry Perl](https://strawberryperl.com/)**: distribución de Perl para Windows, a veces necesaria como dependencia de MikTeX.

## Documentación

- **[Documentación de Overleaf](https://www.overleaf.com/learn)**: guías oficiales de LaTeX del editor colaborativo Overleaf.
- **[TikZ](https://tikz.dev/):** Crear elementos gráficos para latex, también puede ser usado en obsidian.
