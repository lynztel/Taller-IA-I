> [!info] Qué es un IDE
> Un IDE (entorno de desarrollo integrado) es el programa donde se escribe, prueba y depura código. Los de esta lista además traen IA integrada para ayudarte mientras programas.

- **[VSCode](https://code.visualstudio.com/)**: editor de código de Microsoft con extensiones; consultar su documentación oficial.
- **[Antigravity IDE](https://antigravity.google/product/antigravity-ide?ref=kwmr.me)**: IDE agéntico de Google.
- **[Cursor](https://cursor.com/download)**: editor de código con IA integrada de fábrica, viene de una bifurcación de VSCode.
- **[OpenCode](https://opencode.ai/)**: agente de código de código abierto que corre desde terminal.
- **[Google AI Studio](https://aistudio.google.com/)**: plataforma web de Google para probar sus modelos Gemini sin instalar nada.

## Recursos de desarrollo

- **[WindowsDeveloperConfig](https://github.com/microsoft/WindowsDeveloperConfig/)**: script oficial de Microsoft para configurar un entorno de desarrollo en Windows.
- **[Python](https://www.python.org/)**: sitio oficial del lenguaje.
- **[NodeJS](https://nodejs.org/es)**: sitio oficial del entorno de ejecución de JavaScript.
- **[Codewiki](https://codewiki.google/)**: genera documentación de un repositorio de código de forma automática.
- **[Mapas climáticos globales](https://earth.nullschool.net/)**: visualización en tiempo real del viento, el clima y las corrientes oceánicas del planeta.

### Inspiración para diseño

Referencias de estilo:

- **[Awwwards](https://www.awwwards.com/)**: galería de sitios web premiados por su diseño.
- **[Refero Styles](https://styles.refero.design/)**: galería de referencias de estilo visual.
- **[Motionsites.ai](https://motionsites.ai/)**: inspiración de sitios con animación.
- **[Mobbin](https://mobbin.com/)**: capturas reales de apps móviles y web, organizadas por patrón de interfaz.
- **[Aceternity UI](https://ui.aceternity.com/)**: componentes de React con efectos ya resueltos.
- **[React Bits](https://reactbits.dev/)**: componentes y animaciones para React.

Animaciones:

- **[OriginKit](https://www.originkit.dev/)**: kits de animación para interfaces.
- **[Casberry Particles](https://particles.casberry.in/)**: generador de efectos de partículas para web.
